# ExManager MemoryBench

**Не превращайте «наверное во вторник» в подтверждённую встречу.**

Публичный стенд для сравнения обычного RAG, Hindsight, Graphiti и Mem0 OSS.
[Запуск и устройство](README.md) · [Протокол](docs/PROTOCOL.md) · [Зачем граф](docs/GRAPH.md)

## Что получилось в частном прогоне

| Конфигурация | Рабочие вопросы |
|---|---:|
| RAG: BM25 + векторы + RRF | 10/10 |
| Hindsight | 9/10 |
| Mem0 OSS | 9/10 |
| Graphiti, поиск по связям | 1/10 |
| Graphiti, комбинированный поиск по тому же графу | 1/10 |

Это14 записей,10 связанных вопросов, один прогон GLM-5.3-Flash и1536 токенов найденного
контекста. Это не рейтинг продуктов:нет закрытой независимой выборки, повторных прогонов
и существенной проверки многошаговых зависимостей. На результат влияют извлечение,
настройки поиска и упаковка контекста. Подробности и расходы в
[отчёте](reports/2026-10-17-private-calibration.md).

Полезная ошибка:извлечённая память потеряла неопределённость из исходного сообщения.
Hindsight и Mem0 ответили увереннее, чем позволял источник. Дополнительное чтение оригиналов
по уже найденным идентификаторам исправило этот пример; основные оценки не переписаны.

## Что опубликовано

Самостоятельно написанный переносимый runner, четыре нативных адаптера, дополнительный
комбинированный поиск Graphiti, локальный шлюз модели/embeddings,15 офлайн-тестов,
вымышленные сценарии и агрегированные результаты частного прогона.

Личные переписки, реальные контакты, ключи, закрытые адреса и базы не опубликованы.
Публичные примеры придуманы заново. Их результаты нельзя выдавать за воспроизведение
цифр частного прогона; публичный runner не является побайтовой копией исходного стенда.

```bash
python -m unittest discover -s tests -v
python run.py rag --output .runs/validation --validate-only
```

Эти проверки не требуют ключей или запуска моделей. Они проверяют формат данных и оценивание,
а не работоспособность всех внешних сервисов. Для реального запуска нужен свой разрешённый
LLM endpoint; Hindsight и FalkorDB настраиваются отдельно. Команды и ограничения в
[основном README](README.md). Закрытые результаты собственного запуска сохраняйте вне Git.

## Зачем всё-таки граф

RAG и граф не противоположности. Граф может помогать найти цепочку
«человек → задача → блокируемый этап → проект», а RAG и первоисточники подтверждают содержание.
Сначала стоит проверить добавочную пользу графа на таких цепочках, изменении ответственных
и разграничении доступа. Этот репозиторий не подключает новую память к боевому ExManager.

GitHub Actions в этой публикации не включён:у текущего ключа нет права создавать workflows.
[Пример CI](docs/ci-example.yml) сохранён как неактивный файл. Все15 проверок выполнены локально.
